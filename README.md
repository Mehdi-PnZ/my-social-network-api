# My Social Networks API

Refonte des API événementielles et communautaires (TP Développement d'un Web Service).

## Documentation Postman

- **Lien public Postman :** https://documenter.getpostman.com/view/45161265/2sBYHbrvn4

## Installation

1. Cloner le dépôt
2. Installer les dépendances : `npm install`
3. Copier `.env.example` vers `.env` et configurer les variables
4. Lancer en développement : `npm run dev`
